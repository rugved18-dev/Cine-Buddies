# CineBuddies Backend

This directory will contain the CineBuddies backend service, to be developed using Java and Spring Boot with PostgreSQL.

## Planned Technology Stack
- **Language**: Java 17+ / 21
- **Framework**: Spring Boot 3.x
- **Database**: PostgreSQL
- **Architecture**: RESTful API to support frontend client requests (rooms, lobbies, movie recommendations, group voting, and preferences)

Backend initialization and implementation will be performed independently in a future milestone.
