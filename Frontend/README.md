# Midnight Movie Match

Please build the complete Movie Night Planner web application according to the attached master specification (Project Movie Night Planner.md). Follow all requirements: implement all 11 screens (Landing, Sign In, Sign Up, Create Room, Join Room, Room Lobby, Preference Collection, Group Analysis, Recommendations, Group Voting, Final Result), the cinematic dark UI palette (#101116 background, #191B24 secondary, #272A36 elevated, #8B70E8 primary purple), reusable 2:3 aspect ratio placeholder poster cards with Lucide icons (no external poster images), separate mock service architecture ready for future Spring Boot APIs, and complete end-to-end interactive flow for the 3 friends.
